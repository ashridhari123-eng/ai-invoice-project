Developer onboarding · Self-study bootcamp

Procure-to-Pay
from zero to shipping

A four-module path for a developer who's never seen a purchase order — ending with you building an AI-powered P2P application integrated with Zoho Books. Do the modules in order; each one's exercises are the entry ticket to the next.

PR→ RFQ→ PO→ GRN→ INV→ PAID
MODULE 01 · DOMAIN

Procure-to-Pay Fundamentals

The nine-step lifecycle, every document (PR, RFQ, PO, GRN, invoice), approvals & DOA, 2/3-way matching, budgets, GST/TDS/MSME essentials, and the KPIs on the reference dashboard.

17 slides · ~2 hrs · quiz + paper-matching exercise
MODULE 02 · ENGINEERING

Building the P2P Application

Turning the dashboard screenshot into a spec: tech stack, data model, document state machines, the approval workflow engine, RBAC, APIs, KPI queries, and a 14-week milestone roadmap.

12 slides · ~3 hrs · design + build exercises
MODULE 03 · AI

AI Modules: RFQ Comparison & Invoice Extraction

Landed-cost normalisation and weighted scoring for quote decisions; the email → extraction → validation → 3-way-match pipeline; schema-first prompting, confidence routing, evals, and guardrails.

11 slides · ~3 hrs · working code exercises
MODULE 04 · ERP

ERP Integration with Zoho Books

What an ERP does, the app↔Books dictionary (bills ≠ invoices!), system-of-record boundaries, OAuth, pushing vendors & bills, pulling payments, idempotent sync, and reconciliation — plus the capstone demo.

11 slides · ~2.5 hrs · weekend lab + capstone

How to run this bootcamp

  1. Open any module in a browser and navigate with the ← → arrow keys (or the buttons bottom-right). Your position is saved in the URL, so you can bookmark mid-module.
  2. Do every exercise before advancing. The paper 3-way match in Module 1 and the extraction script in Module 3 are non-negotiable.
  3. Demo after each phase of the Module 2 roadmap — working software every two weeks.
  4. Verify external specifics (Zoho endpoints, tax rates, MSMED thresholds) against current official sources before relying on them; treat the slides as the map, not the territory.
